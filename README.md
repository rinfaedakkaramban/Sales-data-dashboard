# 📊 Sales Data Dashboard

An interactive **Sales Data Dashboard** designed to analyze sales performance across products, regions, and time periods. The dashboard provides a clear overview of total sales, sales amount, product performance, and regional performance.


## 🎯 Project Overview

The Sales Data Dashboard transforms sales data into meaningful visual insights through interactive filters and charts.

The dashboard allows users to:

- Monitor overall sales performance
- Analyze sales by product
- Compare sales across different regions
- Track sales trends over time
- Filter data by date, region, and product
- View key performance indicators (KPIs)

## 📊 Dashboard Features

### 🔹 Filters

The dashboard includes interactive filters for:

- **Date**
- **Region**
  - East
  - North
  - South
  - West
- **Product**
  - Keyboard
  - Monitor
  - Mouse
  - Printer
  - Scanner
  - Speaker

### 🔹 Sales Analysis

The dashboard provides multiple visualizations:

- **Sales by Amount** – Monthly sales trend
- **Sales of Product** – Sales performance by individual product
- **Sales by Region** – Comparison of sales across regions
- **Total Amount** – Overall revenue generated
- **Total Sales** – Total number of sales

## 🛍️ Product Analysis

The dashboard analyzes sales for:

- Keyboard
- Monitor
- Mouse
- Printer
- Scanner
- Speaker

This makes it easier to identify which products contribute most to overall sales.

## 🌍 Regional Analysis

Sales can be analyzed across four regions:

- East
- North
- South
- West

Users can select individual regions to focus on specific geographical performance.

## 📅 Time Analysis

The dashboard provides a monthly sales trend, allowing users to analyze changes in sales throughout the year.
